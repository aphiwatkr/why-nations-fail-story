# 🏮 โคมแก้ว — นิทานเมืองกติกา (Why Nations Fail for kids)

นิทานภาพอ่านออกเสียงให้เด็กฟัง 15 บท / 45 ตอน (ตอนละ ~5 นาที) ปรับจากแนวคิดหนังสือ
*Why Nations Fail* (Daron Acemoglu & James Robinson) — เล่าผ่านหมู่บ้านสัตว์การ์ตูนคู่
ซันนี่เวล ↔ หมอกทึบ และเมืองต่าง ๆ ที่จิ้งจอกนักสืบไรอั้นกับนกฮูกาฮูก้าเดินทางไปเยือน

- ภาพประกอบ: SVG แบนส์สร้างด้วยโปรแกรมทั้งหมด (`tools/genart.mjs`, 40 ตัวละครสัตว์ + 45 ฉาก)
- ตัวอ่าน: SPA ไฟล์เดียว `index.html` — สารบัญ, ◀ ▶ + คีย์บอร์ด + swipe,
  ธีมกลางวัน/ก่อนนอน, จำตำแหน่งอ่านต่อ, คำถามนุ่ม ๆ + เกร็ดผู้ใหญ่ท้ายบท
- ใช้งานได้ทั้งออนไลน์และเปิดไฟล์ตรง ๆ (file://) — ไม่มี network dependency

## เปิดอ่าน
GitHub Pages URL อยู่ในหน้า About ของ repo / หรือเปิด `index.html` ตรง ๆ ก็ได้

## โครงสร้าง
```
index.html      ตัวอ่าน (เปิดอันนี้)
js/ch01-15.js   บทพูดข้อมูล (prose) ตอนละ 3 ตอน
assets/         ภาพฉาก 45 + ปก + avatars 40 ตัว (assets/c/)
tools/          ตัวสร้างภาพ (node tools/genart.mjs) + ตัวตรวจบท
```
